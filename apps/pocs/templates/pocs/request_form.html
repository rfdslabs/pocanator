Example Prompts by Vulnerability Type

General Information:

  • Version details: "Target is running Node.js v14.17.0 with Express 4.17.1"
  • Environment constraints: "The target has SELinux enabled in enforcing mode"
  • Specific libraries: "Please use Requests library for the HTTP client portion"
  • Reproduction settings: "The affected server is behind basic authentication with username 'admin'"

For Remote Code Execution:

  • Specific target details: "Target is a Docker container running PHP 7.4 on Apache"
  • Command execution goals: "PoC should demonstrate reading /etc/passwd file"
  • Constraints: "The server blocks certain characters like semicolons and backticks"
  • Network details: "Service is exposed on port 8080"

For Cross-Site Scripting:

  • Target details: "Application is built with React 16.8 and doesn't use CSP"
  • Goal: "PoC should demonstrate an alert box with document.cookie"
  • Constraints: "The application uses DOMPurify but with default settings"
  • Context: "The XSS vulnerability exists in the profile name field"

For SQL Injection:

  • Database details: "Target is using MySQL 5.7 with PDO driver in PHP"
  • Goal: "Demonstrate extraction of user table contents"
  • Constraints: "Login form uses prepared statements but search doesn't"
  • Schema info: "Database has a 'users' table with 'username' and 'password' columns"
Expert Tips for Better Results
Do Include
  • Specific version numbers of affected software
  • Environmental details (OS, frameworks, libraries)
  • Input validation details or filter avoidance techniques
  • Authentication requirements of the target system
  • Target functions or endpoints where the vulnerability exists
Avoid Including
  • Sensitive information like real credentials
  • Internal hostnames or IP addresses
  • Information unrelated to the vulnerability
  • Vague or overly general requests
  • Production environment details
Tip: Enabling "Deep Thinking Mode" is recommended for complex vulnerabilities or when you need more detailed explanations of how the exploit works.
